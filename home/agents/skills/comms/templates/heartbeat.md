# Heartbeat

Use it for a scheduled update when little changed, and for the first answer to a request. Rules: A2, A3, A4.

```
<name>, <progress in one clause, in the reader's currency>.
Next update: <day and time>.
```

For a first answer to a request:

```
<name>, I see it. <result, or what I will do>. I will report by <day and time>.
```
