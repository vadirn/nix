# Check-in

Use it each Friday for the Basecamp question. It serves staffing visibility and belonging. Rules: A4, B8.

The minimum size is two lines:

```
<what I work on, and how loaded I am>.
<one thing from the week: a finding, a surprise, or a thing I enjoyed>.
```

The draft supplies the first line from the week's messages. The second line must come from the user, because it carries the relational value. The draft leaves it as a question:

```
[What stood out for you this week?]
```
