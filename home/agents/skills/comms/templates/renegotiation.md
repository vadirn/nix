# Renegotiation

Use it on the second revised estimate for one item. Send it to the Accountable person first, then to the Sponsor. Rules: A6, A7, A8.

```
<name>, the target for <work> no longer fits.

- Agreed: <target and date>
- Now: <where the work stands>
- Why: <what I learned that changed the estimate>
- Options:
  1. <keep the date, cut scope to ...>
  2. <keep the scope, move the date to ...>
  3. <another way, if one exists>
- I recommend <option>, because <reason in the reader's currency>.

Can we decide by <day and time>?
```

This message carries relational value. The draft fills the facts. The user rewrites "Why" and the recommendation in their own words.
